# 公开仓库审计记录

日期：2026-09-04
范围：`master` 当前代码、公开文档、用户端本机服务、生成素材清单和团队协作入口。

## 当前结论

- GitHub 仓库已公开，默认分支为 `master`。
- 本地 `master` 与 `origin/master` 在本轮开始时均指向 `1b9fad4`。
- 演示客户端、API 契约、平台基线、素材测试和本机 AI 试点均有可重复校验命令。
- 公开仓库不等于生产就绪；账号、持久化、服务端学习事实结算、正式 AI Gateway、内容安全和运维闭环仍未完成。

## 本轮处理

- 静态服务器现在只公开用户端入口、源码和 `assets/generated/source` 素材，不再按路径直接暴露 README、配置、测试或服务端文件。
- AI 接口对 JSON `null`、数组和非法 JSON 返回明确的客户端错误；无效请求不会消耗本机 AI 日额度。
- 知识库表单保存原始文本，由渲染层统一转义，避免特殊字符显示为二次转义实体。
- `.codegraph/` 和 `%SystemDrive%/` 加入 `.gitignore`，避免本地工具产物误提交。
- 增加 GitHub Actions，在 `master` 的 push 和 PR 上自动运行契约、平台、客户端、AI 试点、素材和格式检查。

## 已知限制

- 演示数据保存在浏览器内存，刷新后恢复初始状态。
- 私有 AI 适配器只有本机内存 IP 日额度，尚无账号级配额账本、持久化审计、幂等、内容安全、成本结算和 kill switch。
- 生成素材仍需艺术、内容、版权、无障碍和性能复核；`asset-manifest.json` 当前标记为候选状态。
- 真实上线前必须完成隐私、内容、未成年人保护、数据合规、版权和上线审批评审。

## 团队同步规则

代码、测试、素材清单和功能文档必须在同一个 PR 中同步更新。页面改动需要附路由和截图；接口改动需要同步 OpenAPI、事件 Schema 或安全文档；新增素材需要稳定 `asset_id`、来源、用途和审核状态。
